# ¡Tu gran noche! · mandos

Página que abren los móviles para jugar a «¡Tu gran noche!»: se elige el nombre y se responde
a las pruebas. Se conecta con la tablet por internet (Supabase Realtime) con el código de sala
que sale en la tele.

La genera el juego (`scripts/pulsadores_red.gd`, constante `PAGINA`); no se edita a mano.
